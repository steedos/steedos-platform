✅ 1.3 关键发现

1. 字段定义无独立文件
   - ❌ 不存在独立的 .field.yml 文件
   - ✅ 所有字段内嵌在对象的 fields: 部分中

2. 必填字段确认
   - 对象: name 是唯一必填字段
   - 触发器: name, listenTo, when, handler
   - 函数: name, objectApiName, script
   - 按钮: name 是唯一必填字段
   - 服务: name, namespace

3. Lookup 字段特殊性
   - reference_to 可以是字符串、数组或 JavaScript 函数
   - 函数会在运行时动态查询（例如查询启用了 notes 的对象）

4. JavaScript 代码块
   - handler 和 script 都是纯 JavaScript（支持 async/await）
   - 有 objects 全局命名空间可访问数据
   - 有 ctx 上下文对象（ctx.getUser, ctx.params 等）
   - 有 _, moment, validator 等工具库

5. YAML 特殊语法
   - JavaScript 函数: !<tag:yaml.org,2002:js/function> |-
   - 函数字面量: !!js/function |
   - 多行字符串: >- (保留换行)

                       5. 常见错误与正确做法
================================================================================

❌ 错误                          ✅ 正确做法
─────────────────────────────────────────────────────────────────────────────
创建 .field.yml 文件           字段定义内嵌在对象的 fields: 中
lookup 缺少 reference_to       必须有 reference_to 指向对象
when: afterInsert              必须是数组: when: [afterInsert]
缺少 name 字段                 所有文件都需要 name 字段
handler/script 中无法访问对象  objects 是全局变量，直接使用
缺少权限集配置                 必须有 user 和 admin 两个权限集
─────────────────────────────────────────────────────────────────────────────
